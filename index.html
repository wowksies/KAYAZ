Before you buy

Worth knowing.

Four things people ask most. Anything else, the support server answers faster than a contact form.

Which Windows versions are supported?

The build targets Windows x64. The development notes don't list tested releases, so Windows 11 is not confirmed either way. Ask about your exact version in the support server before checkout.

What exactly is included?

Player ESP, skeleton visuals, aim controls, the ESP filters, the in-game menu and saved configs: everything in the list above. Chams are still in development and are not part of what you get today.

Will it survive a Siege update?

Game patches can break compatibility, and there's no promise otherwise. Check which Siege build is currently confirmed in the support server before buying, especially right after a patch.

Anything to set up first?

Run Siege in borderless or windowed mode. BattlEye has been tested per the development notes, but compatibility and account safety are not guaranteed. Delivery and refund terms are shown by SellAuth at checkout, so read them there.
